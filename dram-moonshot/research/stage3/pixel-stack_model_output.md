## 9. GO / NO-GO

Headline: Cs 0.45 fF fits a 52 nm lateral capacitor; per-tier footprint 0.0110 um2; 0.0432 Gb/mm2 per tier; 1-beta break-even at 10.4 tiers; 64 tiers = 2.76 Gb/mm2 (6.2x 1-beta) at 0.40x 1-beta $/bit ($0.58/GB, before learning-curve); signal 50 mV; modelled readout residual 14.7 mV (21.5 mV without decision feedback) against 29.5 mV allowed; tail retention 1.08 s at 85 C.

**GO/NO-GO line (decisive experiment: planar IGZO pixel-amp array, 85 C).** Measure the post-CDS readout residual = 3.72 sigma of the random read noise + 1e-4 RTN tail + worst-pattern neighbour coupling, on 3-3.5 fF floating nodes read by an oxide SF with gate area <= 0.01 um2. **GO if <= 15 mV** (Cs can fall to 0.26 fF, so the 0.45 fF / 52 nm plan keeps ~15 mV for 3D-only effects the planar test cannot see). CONDITIONAL GO at 15-30 mV (0.45 fF still closes, no spare). **NO-GO for the concept as pitched above 30 mV** (the 0.45 fF / 30-60 nm capacitor claim fails). Between 30 and 65 mV a degraded fallback survives (Cs 0.45-1.0 fF, capacitor <= 125 nm, 64 tiers ~4-6x 1-beta). Above 65 mV the oxide amp tier is dead (footprint >= 0.016 um2, the edge over the A1 base case collapses). Retention gate, same run: tail node leakage <= 34 aA (>= 1 s at 75 mV droop) after a 400 C / hydrogen sequence with access-TFT dVt < 20 mV; NO-GO if > 101 aA. Revival path for a NO-GO: the Smart-Cut c-Si sense layer of I-11545 (N-48), which the cost table prices at ~1.7x the oxide amp tiers.
